# 直齿轮参数化啮合实验室（Gear Lab）

纯浏览器、无后台的教学工具：用参数化方式演示**齿数 z、模数 m、压力角 α** 如何影响
一对外啮合直齿圆柱齿轮的尺寸、齿形与运动，并检查中心距、根切与局部干涉。

- Vue 3 + TypeScript：尺寸/参数输入与状态
- Three.js：齿廓、参考圆、啮合线、接触点与运动（俯视正交相机）
- Clipper2 **WASM**：两齿轮轮廓的布尔交，数值复核接触与局部干涉
- IndexedDB：本地保存/载入案例（无服务器）
- JSON 导入/导出：案例与轮廓，坐标一律 mm，可重新载入复现

## 运行

```bash
npm install
npm run dev        # 开发
npm run build      # 类型检查 + 产出 dist/（含独立 .wasm）
npm run preview    # 预览构建产物
npm run verify     # 运行无浏览器几何/WASM 核对脚本
```

## 教学要点与实现约定

1. **内部一切长度恒为毫米**。界面单位（mm/cm/m/in）只做显示换算，
   切换单位不会改写模型尺寸；导出文件中的坐标也固定为 mm。
2. **渐开线公式与适用范围**（界面右侧可展开）：
   - 参数方程 x=r_b(cos t+t sin t)、y=r_b(sin t−t cos t)，t=tan α_t；
   - 渐开线只在 ρ≥r_b 存在（基圆内无渐开线）；
   - 齿厚半角 ψ(ρ)=s/2r+inv α−inv(arccos(r_b/ρ))。
3. **正确啮合 ≠ “按转速比反向旋转”**。除传动比 i=ω₁/ω₂=z₂/z₂、外啮合反向之外，
   程序用安装相位方程让齿廓在节点处**公法线与啮合线重合**：
   φ₁=π+ψ₁、φ₂=+ψ₂，θ₁=φ₁+θ、θ₂=φ₂−(z₁/z₂)θ；
   接触点沿固定啮合线运动 ξ=r_b1·θ+n·p_b。任一相位的理论接触点都会被数值检验
   确实落在两轮齿廓上（误差仅为折线弦误差）。
4. **检查项**
   - 基圆 r_b=r cosα、分度圆 r、齿顶/齿根圆；
   - 中心距：标准 a₀=r₁+r₂；拉开则 cos αw=a₀cosα/a 并产生侧隙；小于 a₀ 报顶死；
   - 根切：z<z_min=2ha*/sin²α 时提示（20°、ha*=1 严格 z_min=17.097）；
   - 重合度 ε=gα/p_b；ε<1 报传动不连续；
   - Clipper 暂停检查与整周期扫描：区分接触点附近的折线数值残差（绿）
     与真实局部干涉（红，如顶刃/过盈安装）。
5. 先限定：**外啮合、标准齿无变位、理想刚性、无制造误差**；
   基圆与齿根圆之间用径向直线+齿根圆近似（非真实刀具摆线），
   故非接触区干涉判定偏保守，界面已注明。

## 核对脚本 `verify/`

`npm run verify` 用标准与极少齿数样本核对：

- A 解析尺寸（r/r_b/r_a/r_f/p/s、z_min、中心距、啮合角、重合度≈1.605）；
- B 齿形闭合（首尾、逆时针、径向范围、旋转对称）；
- C 接触点在齿廓上、θ=0 为节点（证明用的是正确相位而非仅转速比）；
- D 外啮合转向相反、角速比 z1/z2；
- E Clipper WASM 整周期扫描：标准对无真实干涉，过盈中心距检出干涉；
- F 导出轮廓 JSON 可重新载入并逐点复现。
